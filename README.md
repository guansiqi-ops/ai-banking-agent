# AI Banking Agent - 智能银行助手

> 深圳国际金融科技大赛参赛作品

## 📖 项目简介
基于大语言模型的AI银行智能体，用户通过自然语言对话即可完成银行业务操作，实现"说话就能办业务"。

## ✨ 功能特性
- 💰 智能转账（人名/手机号/定时）
- 👥 AA收款拆分
- 📊 账单分析（月度/年度/异常检测）
- 📈 风险评估与理财推荐
- 💳 卡片管理（冻结/挂失/申请）
- 📋 订阅管理（取消/续费）
- 🔐 三级权限分级（绿/黄/红）
- 📝 操作审计日志

## 🛠️ 技术栈
| 类别 | 技术 |
|------|------|
| 后端框架 | FastAPI + Uvicorn |
| 大模型 | DeepSeek API |
| 前端 | HTML/CSS/JavaScript |
| 语言 | Python 3.11+ |
